# MidiToWavConverter
It is Python Midi To Wav Converter in CLI. I will change it to GUI, and add more function, make for function conviniently..

Helped by AI

HOW TO USE

Copy your midi file and soundfont in same directory with py file. and run it. and then input midi file name, soundfount file name, drum instrument number **ACCURATELY** (or it will cause directory error). and that will create Wav file from your midi and soundfont.
